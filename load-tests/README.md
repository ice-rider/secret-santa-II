# Load Testing for Secret Santa Backend

Набор инструментов и скриптов для нагрузочного тестирования бэкенда Secret Santa с акцентом на аутентификацию.

## Цели тестирования

- Оценка производительности с учетом аутентификации и авторизации
- Проверка стабильности работы под нагрузкой с реальными сценариями
- Определение времени отклика API при использовании защищенных эндпоинтов
- Выявление узких мест в производительности при аутентификации

## Содержимое

- `simple-auth-test.js` - Основной тест с регистрацией, аутентификацией и использованием токенов
- `package.json` - Зависимости проекта

## Требования

- Node.js (для JavaScript тестов)
- Установленные зависимости: `npm install axios`

## Быстрый старт

1. Убедитесь, что бэкенд запущен на `http://localhost`
2. Установите зависимости: `npm install axios`
3. Запустите тест: `node simple-auth-test.js http://localhost 5 3`
4. Проанализируйте результаты

## Тестируемые эндпоинты

- `POST /api/auth/register` - регистрация пользователя
- `POST /api/auth/login` - вход пользователя
- `GET /api/users/me/games` - получение игр текущего пользователя
- `GET /api/games/{id}` - получение конкретной игры
- `POST /api/games` - создание новой игры

## Параметры запуска

```bash
node simple-auth-test.js [URL] [concurrentUsers] [requestsPerUser]
```

Где:
- `URL` - адрес сервера (по умолчанию: http://localhost)
- `concurrentUsers` - количество одновременных пользователей (по умолчанию: 5)
- `requestsPerUser` - количество запросов на пользователя (по умолчанию: 3)

## Результаты тестирования

После выполнения теста выводятся:

- Общее количество операций
- Количество успешных/неудачных операций
- Процент успеха
- RPS (запросов в секунду)
- Среднее время ответа
- Результаты по каждому пользователю отдельно
- Перечень тестируемых эндпоинтов
