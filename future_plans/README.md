# Планы на будущее

В этой директории находятся планы по развитию проекта для трех команд фронтенд-разработчиков. Каждая команда работает независимо над своими задачами, но результаты интегрируются в общее приложение.

## Команды

- **Команда 1**: Миграция UI-компонентов и аутентификации
- **Команда 2**: Миграция игровой логики и страниц
- **Команда 3**: Миграция архитектуры и инфраструктуры

Каждая команда работает по своему плану, описанному в соответствующем файле.
